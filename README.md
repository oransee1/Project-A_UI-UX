# Project-A_UI-UX
AI 기반 UI/UX 디자인 시안 제작 프로젝트 진행

# 프로젝트 개요
- 웹페이지 이름: 대전 맛집있슈
- 목적: 사용자 위치 및 지역, 메뉴를 기반으로 대전 지역 맛집 정보 제공
- 디자인 컨셉: 깔끔하고 직관적인 모바일 앱 스타일 (화면 하단 네비게이션 바 포함)

# 핵심 기능 및 화면 구성 가이드

1. 메인 홈 화면 (오피넷 홈 화면 벤치마킹)
- 상단: '대전 맛집있슈' 로고 및 식당 이름 검색 바
- 중앙: 둥근 모서리를 가진 카드 형태의 메인 메뉴 버튼들 배치
  * 버튼 1: '내 주변 맛집 찾기' (GPS 아이콘)
  * 버튼 2: '지역별 맛집 찾기' (지도 핀 아이콘)
  * 버튼 3: '메뉴별 맛집 찾기' (음식 아이콘)
- 하단 고정 네비게이션 바(GNB): [관심/찜], [홈버튼], [공지사항], [설정] 아이콘 구성

2. 내 주변 (GPS 기반 검색 화면)
- 상단: 반경(예: 1km, 3km), 메뉴 필터, 정렬(별점순, 리뷰순) 드롭다운 메뉴
- 중앙: 화면의 상단 절반은 카카오맵/네이버지도 API를 연동할 수 있는 지도 영역으로 구성하고, 현재 위치(내 거리의 GPS)를 표시
- 하단: 지도 아래에는 반경 내 맛집 리스트를 카드 형태로 제공 (식당명, 거리, 대표메뉴, 평점 포함)

3. 지역별 검색 화면
- 상단: 대전광역시 각 구를 선택할 수 있는 2개의 드롭다운 메뉴 제공
  * 첫 번째 드롭다운: '대전광역시' (고정)
  * 두 번째 드롭다운: 동구 / 중구 / 서구 / 유성구 / 대덕구 중 선택
- 검색창: 특정 식당 이름을 입력할 수 있는 텍스트 박스
- 하단: [맛집 찾기]라는 눈에 띄는 큰 버튼 배치 및 최근 검색어 내역 표시

4. 메뉴별 검색 화면
- 다음 5가지 카테고리를 직관적인 아이콘과 함께 그리드(Grid) 형태로 배치하여 선택할 수 있게 구성
  * 한식 / 중식 / 양식 / 일식 / 퓨전(디저트)

5. 설정 화면
- 초기화면 설정 기능 (홈, 내 주변 등 선택)
- 주요 선호 메뉴 설정 (한식, 중식, 양식, 일식 등 다중 선택 가능한 버튼 UI)
- 맛집 검색 기본 반경 설정 기능 및 [저장하기] 하단 고정 버튼
